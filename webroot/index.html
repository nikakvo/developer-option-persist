notes
Configuration lives in /data/adb/dev-options-persist/config and survives module updates. Restore Original puts back the settings the module changed, with the value each had right before the module first changed it, and pauses enforcement until Apply Now or the next reboot. Uninstalling restores them automatically and leaves Developer Options visible if the module hid them.
